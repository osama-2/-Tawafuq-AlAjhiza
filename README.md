# توافقات الأجهزة v0.2

نسخة مراجعة أولى قوية لواجهة التطبيق وقاعدة البيانات.

## ما تم تنفيذه
- الصفحة الرئيسية مقسمة إلى أقسام قطع غيار مستقلة.
- داخل كل قسم: الشركات > الأجهزة > القطع > التوافقات.
- بحث شامل باسم الجهاز أو رقم الموديل أو رقم القطعة.
- قسم البطاريات يدعم رقم إصدار/رقم البطارية ضمن البحث.
- واجهة كاميرا:
  - التقاط صورة أو اختيار صورة.
  - OCR لقراءة اسم/رقم الموديل من الملصق.
  - مطابقة النص مع قاعدة الأجهزة.
- صفحة تفاصيل الجهاز.
- صفحة تفاصيل القطع والتوافقات.
- حالات التوافق:
  - مؤكد
  - مجرّب
  - محتمل
  - غير متوافق
  - غير موثق
- درجة ثقة لكل توافق.
- قائمة مصادر منفصلة وقابلة للتوسع.

## مهم
بيانات catalog.json الحالية هي أمثلة هيكلية فقط وليست توافقات حقيقية.
لن تُعرض بيانات الإنتاج كـ "مؤكدة" إلا إذا كان لها مصدر مسجل ومراجعة فنية.

4. ربط كل توافق بمصدر وتاريخ تحقق.
